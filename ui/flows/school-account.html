Privacy and security

  • The tenant ID in the authenticated token scopes student lists, management operations, chats, and alerts to this school.
  • Daily updates skip guardians without recorded consent. Only configured contact channels can receive messages.
  • Channel credentials are not shown here. The phone number ID is masked to avoid exposing the full configuration value.
  • This build uses a local demo token endpoint. Production deployments should use a managed identity provider, short-lived sessions, role-based access, and audit logs.
